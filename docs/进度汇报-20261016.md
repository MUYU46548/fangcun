## 一、本轮改了什么（4 项）

### 1. 同步按钮不再"整个方块旋转"（暮雨第 9 条）

- **真因**：`#bar .navgroup .ico.syncing { animation: nav-spin … }` 把动画加在 **button 本体**上，
  边框与底色跟着一起转。原话：「整个方块都在旋转，把我气笑了」。
- **改法**：⟳ 包进 `<span class="ico-glyph">`，动画改挂 `.ico.syncing .ico-glyph`。
- **新增守卫**：`scripts/test/check-button-styles.cjs` 第 ④ 条 —— 凡 `@keyframes` 体含 `rotate()` 的，
  宿主选择器最后一段若"只由 class 组成、且其中至少一个 class 出现在模板的 `<button class>` 上" → 失败。
  用"模板里按钮真用过的 class"当按钮语义来源（不硬编码白名单），所以 `.nc-ico` / `.ico-glyph` / `.bk-spin` 不误伤。
- **断言**：`e2e-renderer-web` 新增「同步按钮的 ⟳ 单独包在 .ico-glyph 里」。

### 3. 首启强制同意免责声明（暮雨第 1 条后半）

  短版把**「AI 功能要先看清花钱这件事」**摆在前面（暮雨原话「主要是涉及到钱是非多」）。改字只改这个文件。
- 新增 `desktop/src/renderer/components/DisclaimerDialog.vue`：first-run 强制（**必须滚到底才能勾选**、
  无遮罩关闭、拦 ESC、focus trap）+ view 模式（设置 → 诊断 →「⚖ 免责与知情声明」）。
- App.vue：免责确认**先于**首次运行向导（`pendingAfterDisclaimer` → `bootAfterDisclaimer()`）。
- ⚠ **两条硬规矩**（别踩）：
  1. 确认记录走 **localStorage**（`fc_disclaimer_ack`，带版本号），**不进 `prefs.json`** ——
     它是"这台安装实例上的合规确认"，不是界面偏好；跟 prefs 走会让"换数据目录还继承着已同意"。

  2. **强制模式的遮罩不许用 `.overlay` 这个 class** —— App.vue 全局 Esc 会取 DOM 里最后一个可见
     `.overlay` 并点它的 `.acts .ghost`，那会点到「不同意并退出」把人踢出软件。
