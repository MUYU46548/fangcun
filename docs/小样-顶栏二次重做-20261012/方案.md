## 一、四条反馈的真因（不是"感觉"）

| 暮雨说的 | 真因 | 证据 |
|---|---|---|
| 搜索框太长太恐怖 | 上一轮为了填 `#bar`（`space-between`）留下的空白，把搜索框写成 `flex: 1 1 220px`，**它把全部余量吸走了** | 实测 **877px**（1440 窗）／517px（1080 窗） |
| 折叠按钮文本没了 | 上一轮「只留符号、文字进 title」这一步**收过头了** | 模板里 `{{ allGroupsCollapsed ? '⊞' : '⊟' }}` |
| 返回按钮没了 | 它是 `v-if="canGoBack"` —— **没有历史就整个不渲染**（不是被挤走，是压根不在 DOM） | `App.vue:51` |
| 想加首页/帮助/同步 | 这三个入口**从来没有过** | 全仓 grep 无 `home` / `help` 视图 |

⚠ 上一轮我把「返回按钮被 space-between 甩走」当成唯一病灶修掉了 —— 但**还有第二个病灶**：
`v-if` 让它时有时无。两个病都治才算治好。

**四处改动**：

1. **左侧按钮组**（Edge 式）：`← 返回 · ⌂ 首页 · ? 帮助 · ⟳ 同步`，图标化 ——
   ⚠ **图标不是审美选择，是几何必需**：带文字的版本在 1080 窄窗下**横向溢出**
   （实测需 1023px、只有 999px）。图标版 1440/1080 **都单行不溢出**。
2. **搜索框固定 260px**，不再 `flex: 1`；余量交给一个 `.grow` 撑杆，筛选/分组/排序**继续贴右端**。
3. **折叠按钮文字回来**：「⊟ 折叠」/「⊞ 展开」。
4. **返回按钮常驻**：去掉 `v-if`，无历史时 `disabled` 置灰。

## 五、落地结果（2026-10-12 已实现）

按**甲案**落地（暮雨圈选：「放顶栏左侧（参考 Edge 等），搜索框弄短一点不就行了？不需要那么长」）。

| 反馈 | 真因 | 修法 | 断言 |
|---|---|---|---|
| 搜索框太长（877px） | 上一轮为填 `space-between` 的空白写了 `flex: 1 1 220px` | 固定 `flex: 0 0 260px`；余量交给新加的 `.fbar-grow` 撑杆 | `w<=340` / `flex-grow===0` / 筛选组仍贴右端 |
| 折叠按钮只剩 `⊟` | 上一轮为压宽度砍掉了文字 | 恢复 `⊟ 折叠` / `⊞ 展开` | 文本里必须有「折叠/展开」且不折行 |
| 返回按钮"没了" | **两个病灶**：① 被 `space-between` 甩到上一行（上轮已修）② `v-if="canGoBack"` 根本没进 DOM | 去掉 `v-if` 改成常驻 + 无历史时 `disabled` 置灰 | 常驻 / 无历史时 disabled 且仍在原位 |
| 想加首页·帮助·同步 | 三个入口从来没有过 | 顶栏左侧 `.navgroup`：`← 返回` + `⌂ ? ⟳`（图标版，甲案） | 三入口存在 / 各自真生效 |

**帮助手册**：新建离线 `help-view` 视图（六节 + 两张表，含搜索语法 `due:`），入口唯一（顶栏 `?`，不在页签行重复）。

**同步按钮**：只做按钮、状态自报（暮雨原话）。复用既有 `backup:gitPush` 通道；
成功/失败都写进按钮 `title` + 弹出提示，**不许静默失败**；未配置仓库时 `ok !== true` 也算失败。

## 七、顺带：待办「可选时间」字段（同日第二件）

暮雨原话：「待办只有到期日，建议再加一个可选的时间字段。如 workbuddy 额度 21:33:59 重置，让用户选个 21:39。」

- **独立 `dueTime` 字段**，不并进 `due` —— `due` 被日历/筛选/排序/逾期/Python 侧多处按日期解析，
  独立字段是纯增量、老数据零变化。
- 单一来源：`parseDueAt(due, dueTime)` 合成**分钟级**时间戳 + `daysSinceDue()` / `formatDueTime()`，
  逾期判定与界面显示共用（App.vue 里**不许**内联日期算术，`e2e-calendar` 有守卫盯着）。
- 「没设 ≠ 设成空」：`normalizeDueTime('')` → `undefined`，字段从 JSON 消失。
