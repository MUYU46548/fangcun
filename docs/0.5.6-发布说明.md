## 一、唯一的新功能：撤销能力收口

改错一条日志、改坏一张卡，以前只有「撤回上次保存」一步，且看不到历史。
现在两处都能**看列表、逐版预览、恢复任意一版**：

| 入口 | 能看到什么 | 恢复时 |
|---|---|---|
| 日志编辑弹窗 →「历史版本」 | 每版的时间 / 标题 / 文件大小 / 状态 | 先自动备份当前版，再写入所选版本 |
| 任务卡编辑弹窗 →「历史版本」 | 同上 | 同上 |

- 数据来自早已在写的 `.backup` 文件，**不新增任何隐藏状态**。
- 恢复前**自动备份当前版**（恢复本身也能再撤）。
- 拒绝条件写死：非法文件名 / 路径穿越 / 结构坏掉一律拒写，并说明原因。
- 新增 IPC：`logs:versions` / `logs:versionGet` / `logs:restoreVersion`、
  `tasks:versions` / `tasks:versionGet` / `tasks:restoreVersion`；
  旧的单步 `logs:restorePrev` 死通道已删除。

## 二、渲染层拆分（内部重构，不改行为）

`App.vue` **11,889 → 8,532 行**（总行数 9,230 → 8,532；非空 7,964）。搬走的是「一坨模板 + 一坨状态」，
不是删功能：

- 设置弹窗全部页签（通用 / 诊断 / Agent / 项目 / 备份）→ `components/settings/*`
- 看板三摆法 → `views/BoardView.vue`
- 任务预览 / 日志编辑 / 接力 / 日志清理 / 只读预览 → `components/*`
- 日志全链 → `composables/useLogsView / useLogAttachments / useLogMaintenance / useLogEditGuard /
  useLogEditorSave / useLogStatusActions / useLogImport / useLogEditorOpen / useLogConvert /
  useLogHistory / useLogGroups / useLogAux / useContextMenus`
- 在途一屏 → `views/TripBoardView.vue` + `composables/useTripBoard.ts`
- 通知中心 → `components/NotificationCenter.vue`

外部可见的变化只有一处：**通知中心 / 在途一屏的按钮字体改为继承**（`font-[inherit]`）——
preflight 关着时原生按钮原来会用系统字体，与旁边不是一个字型。

## 安装（本机自用 / 自动更新）

```
desktop/pkg/Fangcun-Setup.0.5.6.exe
```
同目录另有 `.blockmap` 与 `latest.yml`（`latest.yml` 记录的版本 / 文件名 / 字节数与本包一致）。

⚠ 装完若托盘里还挂着旧实例，**请走托盘菜单真退再启动**（本应用**关窗 ≠ 退出**）——
否则会出现「界面是新的、主进程是旧的」这种假象。

⚠ 安装包**未做代码签名**，SmartScreen 可能提示「未知发布者」；这是本机自用/小范围分发的现状。
