## 一、最要紧的一条：LLM 智能层**接了**（REV-005）

契约 ③ 从「本阶段不接」改成「**本阶段接，但 BYOK**」，三条边界一条都没松：

| 边界 | 落地成什么 |
|---|---|
| ① **BYOK** 自带钥匙 | 设置页「模型通道」：端点 / 模型名 / 密钥 / 超时；自带 DeepSeek 一键预设。**默认值全面去国外端点**（桌面与 CLI 的 base_url/model 默认为空），没配就给**人话报错**并指向设置页 —— 方寸不连任何默认端点 |
| ② 产出**只落「待审批」卡** | 项目详情「✨ AI 规划」：拆目标成待审批卡 / 起草项目说明四栏卡。`source=ai-planning` 可审计；验收标准缺省时**强制人工补**（判据禁形容词）；解析失败给**兜底卡**（原文不丢，可人工救） |
| ③ **花销每次可见** | `chatDetailed` 返回 usage（入/出/总 tokens），写回层两个入口与界面 toast 都透传 |

配套：**决策卡**（拍板记录页 —— 群里拍的板当场记成卡：事情/哪天定/还作不作数/出处；三态 作数/已作废/已并入；
幂等记板；有意**不挂任务状态机**）；**合入外部「AI 规划整包」**并灌入 **32 条决策卡 + 24 张卡**。

> 定位没变：仍是「**任务收口 + 方针载体**」。智能在 agent 侧，方寸只把上下文收住 + 留痕，**点头权在用户**。

## 二、看板与顶栏

- **筛选栏改版**（方案 B「条件标签化」）→ **顶栏重做**：一行 14 个控件 → **5 个**；搜索框固定 260px，
  余量交给撑杆；`← 返回` 常驻（无历史时置灰）；新增 **`⌂ 首页` / `? 帮助` / `⟳ 同步`**。
- **帮助手册**：离线视图（6 节 + 2 表，含 `due:` 搜索语法），入口唯一。
- **同步按钮**：只做按钮 + 状态自报，成败都写进 `title` 并弹提示 —— **不许静默失败**。
- **信息卡墙**（含「只看未完成」开关、分区可折叠）；**状态筛选**与「全部项目」正交叠加。
- ⚠ 硬教训记档：**reka-ui 的 Popover 是两层**，`position` 绝不能写在使用方那层（写错 → 浮层跑到视口外）。

## 三、日志与待办

- **修掉「日志 → 待办内容全丢」**：旧实现只取「下一步」首条当标题、且那条是模板占位 `（待填写）`、
  正文一个字不搬 → 整条待办只剩四个字。现改为**首行摘要 + 来源行 + 正文全文 + 下一步全文**。
- **待办「可选时间」字段**（`dueTime`，如 `21:39`）：与到期日合成分钟级时间戳；
  单一来源 `shared/time.parseDueAt`，日历/逾期/排序共用。
- **新增：按日期批量清理「已归档」日志** —— 日志页「清理归档…」→ 选日期 → **先预览命中条数** → 再确认。
  **软删**：移进 `docs/执行日志/.trash/`（**可恢复**），不是硬删。判据是「归档日期**严格早于**所选日」。
- 日志右键补「✏️ 编辑」、批量改优先级、日志 ⇄ 待办双向互转、日志卡显示时分。

## 五、备份与数据安全

- **备份范围补漏**：`policies/` 此前**根本不在包里**（静默数据丢失面）；新增「备份瘦身」两旋钮
  （排除执行日志附件目录 / 跳过超过 N MB 的单文件，默认 10MB），**跳过项逐条记账**进 `manifest.omittedFiles`，
  并新增体积构成报告。
- **Git 通道改推真实文件镜像**（不再往仓库扔压缩包 —— "那要 git 有什么用"），并修掉三处真机真因：
  空仓库被误报失败、clone 失败盲目退化 init 吞掉真因、失败信息形状不一致变成"没有返回结果"。
- **restic 脚本生成**（方案 A）：三条红线 —— 密码不进脚本、密钥文件必须 exclude、**不替用户注册定时任务**。
