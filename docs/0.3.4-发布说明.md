## 更新简介

接上了 **AI 规划（BYOK）**这条线，看板与日志做了几轮减负，外加一个很久没敢动的架构级改动：**开始给方寸搭 UI 基座**。

## 本版内容

### 1. AI 规划：接了，但**钥匙是你自己的**

契约里原本写着「本阶段不接 LLM 智能层」，这一版改成「**本阶段接，但 BYOK**」，三条边界一条都没松：

- **① 钥匙自备**：设置页新增「模型通道」（端点 / 模型名 / 密钥 / 超时），自带 DeepSeek 一键预设。
  **默认值里所有国外端点已清空** —— 没配就给一句人话报错并指向设置页，方寸**不连任何默认端点**。
- **② 产出只落「待审批」卡**：项目详情「✨ AI 规划」可以拆目标成待审批卡、起草项目说明四栏卡。
  AI 不能背着你往看板里塞东西；分析失败还给**兜底卡**（原文不丢，可人工救）。
- **③ 花销每次可见**：每次调用都把 token 用量带到写回入口与提示条上。

另外新增**决策卡**：群里拍的板当场记成卡（事情 / 哪天定 / 还作不作数 / 出处），三态「作数 / 已作废 / 已并入」，
**有意不挂任务状态机**。台账可以直接整表灌进来。

### 2. 顶栏减负：一行 14 个控件 → 5 个

点一下筛选，顶栏直接变三大行 —— 这是被点名过的问题。现在：搜索框固定宽度、筛选/分组/排序贴右端；
左侧收成一小组图标（`← 返回` / `⌂ 首页` / `? 帮助` / `⟳ 同步`）；`← 返回` 常驻，没历史时置灰（以前它会被挤到上一行、
或者压根不在页面里）。新增**离线帮助手册**（6 节 + 2 表）。「同步」只做按钮和状态自报，成败都写在悬浮说明里，**不静默失败**。

### 3. 日志：修掉「转待办内容全丢」，并新增按日期清理

- **转待办内容全丢**（真 bug）：旧实现只取「下一步」的第一条当标题，而那条是模板占位 `（待填写）`，
  正文一个字都不搬 —— 转出来的待办只剩四个字。现在**首行摘要 + 来源行 + 正文全文 + 下一步全文**。
- **按日期批量清理「已归档」**：日志页「清理归档…」→ 选日期 → **先看命中条数** → 再确认。
  是**软删**：文件移进 `docs/执行日志/.trash/`，**可找回**，不是一键永久删除。
  改日期会自动作废上一次预览（免得"预览 71 条、按新日期删"这种对不上的假象）。

### 4. 待办可以带「时间」了

待办的时间点除了日期还能填 `21:39` 这种，日历、逾期判断、排序都用同一个来源算，不会各算各的。

### 5. 项目监控台 & 在途一屏

- 点项目卡直接进**项目监控台**：完成率环、几个大数字、健康度左缘色条（只有异常才显示）、阻塞源入口、仓库提交活动。
  数据缺了就写「—」并给一个「拉取」按钮，**不编值**。
- 修掉在途一屏「未提交」列恒空的老问题；新增「复制 AI 提示词」——把"让 AI 去填契约"变成一句可直接粘贴的话。

### 6. 备份：补了个静默丢数据的漏

- **`policies/`（项目方针）以前根本不在备份包里**。已补上。
- 新增两个「瘦身」开关（排除执行日志附件目录 / 跳过超大单文件），**跳过什么逐条记账**，另给一份体积构成报告。
- **Git 备份改成推真实文件**（以前是往仓库扔压缩包 —— 那要 git 有什么用），并修掉三处真机上才暴露的失败：
  空仓库被误报失败、clone 失败后盲目初始化吞掉真因、失败信息形状不一致导致界面显示"没有返回结果"。

### 7. 架构图：项目说明卡里可以嵌一张分层图了

任务新增可选字段「架构图」，填一段 JSON 就能在任务详情里渲染成分层架构图。
**它只对项目说明卡有意义，所以别的卡的编辑器里看不到这个框**（填过值的卡仍然看得到，不会把值藏起来）。
JSON 写坏了界面会直说是哪坏了，不留空白。

### 8. 开始搭 UI 基座（第一步：接了但**外观一个像素没变**）

一直手搓控件这件事要收了。这一版先只做"接线"：装上 Tailwind，把规矩定死
（**关掉 preflight**——打开会让全局行高和 Markdown 列表符号变样；**不让它扫老代码**——老 CSS 里有同名类名会被凭空生成规则）。
验收标准是**构建出的 CSS 逐字节不变**，实测 126485 字节、哈希前后一致 —— 零观感回归。
组件真正换血是后面几步的事。

## 其他修复

- 死通道清到 **0**（44 → 0）：能接回界面的接回、确实没用的删掉、其余登记豁免并**写明理由**（扫描器每次运行都会把这份清单打印出来）。
- 日志 → 待办、日志右键编辑、日志批量改优先级；看板信息卡墙（含「只看未完成」开关）与状态筛选。
- 修了一处「主题变量名写错但测试全绿」的坑：架构图色板里用了主题中不存在的变量名，图会整体变黑而断言全绿 —— 现在有守卫逐个复核。

## 已知限制

- **UI 基座只走到第 1 步**：对话框、下拉、菜单、Tooltip、开关这些**仍是手搓的**，会按顺序逐个换。
- **「架构图」字段还没有任何一张卡在用** —— 字段和渲染都通了，喂数据是下一步。
- 规划管理（立规划 → 决策点 → 选择留痕）和路线图趋势**仍未接界面**，体量大，等排期。
- 安装包未做代码签名，Windows SmartScreen 可能提示"未知发布者"。
- 更新检查走 GitHub Releases，需联网。

## 安装

下载 `Fangcun-Setup.0.3.4.exe` 运行安装即可。`latest.yml` 随本 release 一并发布，自动更新依赖它，手动安装请无视。

> 装完若托盘里还挂着旧版本，**请从托盘菜单真正退出再启动**（方寸关窗 ≠ 退出），否则会出现"界面是新的、后台是旧的"这种假象。
