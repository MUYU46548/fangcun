## 一、结论先说

**能自动算出来，而且比手工那个更准。**

那晚我说「编辑器 3 万行 / 生成器 2,711 行 = 92% vs 8%」。现在脚本复算：

| 大块 | 实测 | 那晚手算 |
|---|---:|---:|
| 编辑器（历史剧本 + 建筑内部 + 星域） | **37,407** | 30,314 |
| 生成器（`utils/terrain*` 8 个模块） | **2,711** | 2,711 |
| 账本引擎（`src/ledger`） | **1,110** | 1,110 |
| **编辑器 : 生成器** | **90.7% : 6.6%** | 92% : 8% |

方向和量级都对得上。生成器 2,711 与账本 1,110 **完全一致**（我手算这两栏时口径是对的）；
编辑器那栏我**少算了 7,093 行** —— 因为我按 `scenario/` 目录算，漏了
`utils/scenario*` 12 个模块（3,338 行）和 `components/Scenario*` 7 个组件（9,065 行）。

**这就是手工数的病**：数的人自己不知道漏了哪块，而看数的人没法复算。
现在 `python scripts/layer-profile.py sitian --spec scripts/layer-specs/sitian.json`
一条命令出全部数字，任何人都能复跑、能当场看出我漏了什么。

## 三、这轮实测踩到的五个坑（每个都会让数变成假数）

这一节比上面两节重要。**五个坑全都是首跑时数看起来完全正常、实际全错。**

### ① 一个浏览器 profile 把分母撑到 300 万行

司天根下有 `.test-edge-profile-3d`（523 个扩展文件、**287 万行**）。
第一版没挡隐藏目录，于是「编辑器占 8.9%」，剩下的 91% 是浏览器扩展。
**所有百分比连同结论一起是假的**，而报告长得一模一样。

### ② 拿全仓当分母

第二版挡了浏览器 profile，但分母还是"全部代码行"。于是说完"编辑器 8.9%"，
剩下 91% 其实是**测试**（13.2 万行）和脚本。那不是"编辑器薄"，是**分错了母**。
现在分母是**产品代码**，且报告里明写"不是全仓 X 行"。

### ③ 打包产物被当成产品代码

- 方寸 50 万行"产品代码"里，**36 万行是 `desktop/pkg/win-unpacked`**（打包出来的 Electron 副本）。
- 绒花墨坊 31.9 万行、明鉴 12.7 万行，几乎全是**内嵌 Python 运行时**（`console/runtime/python`、
  `desktop/runtime/python`）。

挡掉之后方寸从 50 万降到 12.7 万，墨坊从 31.9 万降到 3.2 万。

### ④ `.ts` 既是 TypeScript 也是 MPEG 视频分片

「视频制作」项目里 `frames/seg_04.ts` 一片 7,634 行 —— 是视频碎片，不是代码。
不挡的话它会成为全仓最厚的"产品代码"（17.5 万行）。
现在只数**能解码成文本**的文件，二进制一律不算，且逐条点名。

### ⑤ 反过来也错一次：GBK 脚本被当成二进制丢掉

第四版为了挡视频分片，只认 UTF-8。于是 ROSA 的 `96 事务管理/索引预览.bat`
（**GBK 编码的合法脚本，头一行就是 `chcp 936`**）被当成二进制丢掉了 ——
整仓从 31 行变成 **0 行**，而报告上它长得就像"这个库没有代码"。

**这是"拿看不见当成没有"，和第一类的错正好相反。**
现在先按 NUL 字节 + 控制字符比例判二进制，再依次试 utf-8 / gbk / utf-16。

**五个坑的共同点：数字错了，报告看起来完全正常。**
所以每条规则都必须**点名它挡掉了什么**（报告最后两节就是干这个的），
并且有一套 26 条的守卫把这些口径钉死（`node scripts/test/e2e-layer-profile.cjs`，26/0）。
其中三条是**反例自证**：把错装回去，必须当场精确变红。

## 四、做了什么（都是一次性只读脚本，还没进方寸）

| 文件 | 是什么 |
|---|---|
| `scripts/layer-profile.py` | 单项目：层 → 文件数 → 行数 → 占比，+ 与声称的分层对账 |
| `scripts/layer-board.py` | 跨项目横比（上面那张表） |
| `scripts/layer-specs/sitian.json` | 司天**声称的**分层（人给的口径）+ 那晚手算的五个数（用于对账） |
| `scripts/layer-specs/quartz.json` | quartz 的 `public/` 是生成物，按项目声明排除 |
| `scripts/test/e2e-layer-profile.cjs` | **26 条守卫**，含三组反例自证 |

用法：

```bash
python scripts/layer-profile.py sitian --spec scripts/layer-specs/sitian.json
python scripts/layer-board.py --out docs/层厚度-横比-20261116.md
```
