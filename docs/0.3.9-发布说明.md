## 本版内容

### 1. MCP 接入：三处真因，入口形态重做

用户原话：「多个项目都不能正确调用方寸进行记录」。逐条取证：

| 真因 | 证据 |
|---|---|
| 入口在**安装版上从来不可用** | `dist/**` 全进 `app.asar`，外部 node 执行不了 asar 内 js，builder 又没配 `asarUnpack`；配置段写的是裸 `command: node`，而 GUI 应用继承的用户 PATH 里没有独立 node → spawn ENOENT |
| **协议不合规** | 探针原样输出：`notifications/initialized` 和 `ping` 都回 `-32601`。严格客户端（`dsh-mcp-client`）判协议违规 → 丢掉整条会话 |
| Hermes 侧**压根没配** | `~/.hermes/config.yaml` 只有 memory / skills 两段，没有 `mcp_servers` |

现在的形态（零外部依赖）：

```yaml
command: <方寸.exe>            # 开发态 = electron.exe
args:    ["<resources>/app.asar/dist/main/mcp/bridge-standalone.js"]
env:     { ELECTRON_RUN_AS_NODE: "1" }   # 不能省
```

- 走**纯 node 模式**跑包内桥脚本：不初始化 Chromium，也就不会拉起 GPU 进程。
  （试过「Electron 主进程自己收发 stdio」：本机 GPU 进程连崩 6 次后
  `FATAL: gpu_process_host isn't usable. Goodbye.` 直接把进程带走。）
- 协议层补齐：通知（无 id）零回包、`ping` 回 `{}`、工具异常包成 `result+isError`
  而不是退化成传输层错误、`initialize` 回显客户端版本。
- 客户端不支持 `env` 时用「入口 C」：本机 node 跑同一个桥脚本，能力相同。
- 设置页「接入其他 Agent」会按本机路径把上面三段一起生成；`scripts/check-agent-mcp.cjs`
  可现场自检（读 DSH / Hermes 真实配置 → 握手 → 真写一张卡再删）。

### 2. 超期任务批量改期（外部交付包 A）

看板日期筛选「超期」→ 任务多选 → 全选 → 「📅 改期」→ 一键 +7 / +30 天，或指定任意日期。
改完逾期标识按新截止日自动消失，每条改动留痕。零新 IPC（走既有 `batchEdit → updateTask`），
日期用本地日历日，不受时区影响。

### 3. 备份自动清理 + 恢复演练（外部交付包 S）

- **轮换判据改 mtime**：以前按文件名比（名字最新 ≠ 内容最新），现在按真实修改时间。
- **新增体积线**：备份超过份数**或**体积上限就淘汰最旧的，删前可预览、逐条记账。
  默认关闭（`maxLocalMb = 0`），不改变现有行为。
- **半包守卫**（施工中抓到的真坑）：数据根缺 `task-data/` 时，以前会拿 docs 凑数打出
  "成功"的包，恢复时才被拒 —— 现在落盘前就拒绝并说明原因。
- **一条命令的恢复演练**：`node scripts/test/drill-restore.cjs` —— 拿真实备份假装恢复一遍，
  落临时目录、跑完自清，真数据一字节不动。

### 4. 账本卡标题不再砍半截

旧版导入器按**字符**硬切 56 字，于是
`…你自己派了自己，0b0`（原文是 `0b02e48 规划四态）`）—— commit hash 砍掉一半、且没有省略号，
卡面看起来是个完整但读不懂的标题。

现在：放得下就一个字不动（上限提到 80）、非要切就切在自然边界且不许落在 hash / 版本号 /
路径中间、切了必带 `…`。**存量 12 张卡已就地修好**（只改标题那一行，其余字节不动）。
