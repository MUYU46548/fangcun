## 一、总则

1. 方寸是一款**本地优先（local-first）**的个人项目管理工具。它在您自己的电脑上运行，
   数据默认存放在您自己指定的本地目录，采用Markdown+YAML明文存储。
2. 您**开始使用**（安装、启动、或调用其命令行/MCP接口）即表示您已阅读、理解并接受本文件。
   若您不接受，请停止使用并卸载。
3. 方寸**免费提供**。作者不因提供本软件而收取费用，也不对使用结果作出任何承诺。

## 二、软件功能定义

**基础功能**：任务调度台+方针载体。把任务、执行日志、项目方针、决策记录等对齐到同一个入口；
给Agent提供只读任务日志与**经您确认后**的回写通道。

**非方寸功能**：

- 不是项目全周期管理平台，不是流程引擎，不是团队协作SaaS；
- 不是模型服务提供者 —— 方寸**不含**任何预置的大模型服务、不代理任何 API、不代收费用；
- 不是备份服务商 —— 方寸只提供"打包/上传/校验"的工具能力，**存储位置由您指定并负责**；
- 不是您数据的看护人 —— 数据在您本机，最终的保管责任在您。

## 三、数据与隐私

### 3.1数据存储

- 任务、日志、项目方针、决策记录=您指定目录下的**Markdown 文本文件**，可被记事本打开，
  可直接交给git/网盘管理。安装版默认目录为 `%APPDATA%\fangcun-desktop`。
- 方寸**不要求注册账号**，**不内置用户体系**，**不内置统计/埋点/崩溃上报**，
  不向作者或任何第三方服务器回传您的使用数据。

### 3.2联网情况

以下需要联网的情况都由您触发或由您配置。

| 场景 | 会发生什么 | 触发方式 |
|---|---|---|
| **更新检查** | 访问 GitHub Releases 查询是否有新版本（不携带您的任务数据） | 您在设置页点「检查更新」 |
| **您配置的备份通道** | 把**备份包**上传到您**自己填写**的 WebDAV 地址，或推送到您**自己填写**的 Git 仓库 | 您点备份 / 您开了定时备份 |
| **您配置的LLM端点** | 把提示词与相关文本发送到您**自己填写**的模型服务地址 | 您在设置了端点的前提下主动发起一次 AI 动作 |

除此之外，方寸不主动连接任何端点。

### 3.3密钥与凭证

- API Key/WebDAV密码等凭证**只保存在本机**：WebDAV密码通过操作系统的加密存储来保存
  （Windows DPAPI/macOS Keychain，经Electron`safeStorage`），界面回显一律**掩码**，
  对外只回答"是否已设置"。
- **备份包默认不含任何密钥、也不含密钥文件**。
  但请注意：**备份包内容=您的任务数据本身**，上传到哪里就等于把任务数据交给哪里，
  请自行评估目标位置的可靠性。
- ⚠ 您仍应自行防范本机层面的风险（他人使用您的电脑、恶意软件、系统账户被接管等）。
  凭证以可解密形式存于本机，具备本机管理员权限的人或程序有可能读取它。

### 3.4数据出境提示

如果您把LLM 端点、WebDAV、Git仓库指向**境外服务器**，您输入或备份的内容将**跨境传输**。
这属于您的自主选择；请您自行确认符合您所在地区的法律法规与数据合规要求。

## 四、LLM智能层（BYOK）专项条款

方寸的AI能力按**BYOK（Bring Your Own Key）**设计，边界如下：

1. **您是与模型服务方的直接关系。**端点地址、模型名、API Key 由您在设置页自填；
   方寸**不预置**任何端点或密钥、**不连接**任何默认模型服务、**不参与**您与服务方的
   费用结算，也不对您的 Key 是否有效、额度是否充足、服务是否可用负责。
2. **数据流向。**您发起一次AI动作时，方寸会把**完成该动作所必需的文本**（通常包括
   您的提示词，以及被选中的任务/日志/方针内容）**直接发送到您自己填写的端点**。
   该数据随后如何被处理、存储、留存，取决于**模型服务方的隐私政策**，方寸无法控制。
   **不要把您不愿离开本机的信息放进这些内容里。**
3. **费用。**调用产生的费用由您与模型服务方按其实时价格结算。方寸界面给您看的
   Token 用量/估算花销**仅供参考**，不是计费依据；**下单与产生实际费用前，请以服务方
   官网实时价格为准。**
4. **产出即"建议"。**AI生成的内容由方寸落到**“待审批”卡片**，只有**您点过**才会转正。
   方寸不对生成内容的**准确性、完整性、时效性、合法性、可用性**作任何保证；
   您应当在使用前自行核实。**是否采纳、如何使用，责任在您。**
5. **您的输入义务。**您不得借助本功能输入、处理下列内容：违反法律法规的信息；
   他人的个人隐私、商业机密、国家秘密；您无权处理的数据。因您的输入导致的后果由您承担。
6. **服务方可变。**各家模型服务商的数据政策、留存策略、价格、能力随时可能变化，

## 五、备份、恢复与数据丢失风险

1. 备份包由方寸按既定范围（任务数据、项目方针、`docs/`、注册表）打包，并生成
   `.sha256` 校验值与清单文件。
2. 恢复前方寸会做 **sha256+包结构双重校验**；校验不通过会拒绝恢复。
3. **但您仍可能丢数据**，典型情形包括：备份包本身已损坏或不全、上传目标被清理、
   磁盘故障、误删、在恢复时选择了错误的目标目录、跨版本不兼容、您自己关闭了定时备份。
   **请自行建立多重备份习惯，并定期做一次真实的恢复演练。**
4. 您交给方寸的第三方工具（WebDAV 服务商、Git 托管平台、网盘）自身的可用性、
   限流、回收策略与数据归属，由您与服务方之间另行约定，方寸不作担保。
