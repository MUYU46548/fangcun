## 本版内容

### 1. 启动台：点启动只出空壳窗口 —— 真因是「父进程」

现象：点卡片，主进程活着，窗口只剩空壳。同机做过对照才看清：

- 用资源管理器打开同一个 exe（`explorer.exe 路径`）→ 窗口正常；
- 从方寸自己的进程树里直接创建进程 → 子 Electron 应用的 **GPU 进程连崩**
  （`exit_code=-1073741819` → `FATAL:gpu_data_manager_impl_private.cc(448)`），窗口活不下来。

差别不在命令行参数，在**父进程**：从方寸派生，子进程留在方寸的任务树里；由桌面常驻的
explorer 代启动才落到常规位置。这就是"双击好使、启动台不好使"。

现在的做法：

- 无参数的 `.exe` 一律**交给资源管理器代启动**；填了启动参数的仍直接创建（explorer 传不了参数）。
- 启动后**复查进程**（前后两次 tasklist 快照做差集）：出现新 PID 才说"已启动"；查不到就说
  "交给了系统但没复查到进程"，不再无条件报成功。
- 等待期间先给"正在启动…"，并按应用记一个 6 秒防重入（连点不会起两份，失败立刻放开）。

另外补了卡片**右键菜单**（启动 / 编辑登记 / 打开文件夹 / 删除这条登记）和卡片上的 🗑。
删除只删登记，不动磁盘上的应用文件 —— 文案里写清楚。

### 2. 决策卡：从"只能新增"补到有生命周期

原来只能新增一条、改一下三态。写错一个字只能撤销重记，记错一条永远留着。

- **改**：卡片上「✏️ 编辑」就地展开（不弹新窗），内容 / 日期 / 项目 / 出处 / 备注都能改。
- **删**：「🗑 删除」两段式（先变「取消 / 确认删除」），**删前先把这一条完整留底**到
  `task-data/decisions-deleted.md`；留底失败就中止删除。
- **找得到**：搜索框，内容 / 出处 / 项目 / 备注 / ID 五个字段都认；页签计数跟着搜索走。
- **成批动**：多选 → 勾选 → 全选当前 → 批量设为 有效/已撤销/已合并 → 批量删除。
  逐条走同一条通道，留底与活动日志一条不少；批量删除同样两段式。
- **看得见**：每张卡显示「动于 MM-DD HH:MM」。

### 3. 归档与回收站：按状态批量、按日期清理

- 归档页新增「按状态快选」：每个状态一个带计数的按钮。**选择可叠加** ——
  点「完成」再点「驳回」两组都在选，再点一次只取消该组；工具条开头的方框是
  **邮箱同款三态**（全选 / 部分选中呈横线 / 空）。
- 回收站新增「🗓 按日期清理」：选日期 → **先看预览命中几项** → 再确认彻底删除。
  删的是回收站里的文件本身，**不可撤销**，所以文案把这件事说满。

### 4. 按钮与控件统一（不再是两套）

同一页里原来并存三种尺寸：按钮 32/圆角 10、输入框 34/10、原生下拉 30/9；
而且新按钮的次要样式**没有边框**，老按钮是白底描边。现在统一到老那套（扁平圆角 32/8、白底描边）。
**这条有几何断言守着**：决策页六个控件实测必须 h=32、圆角 8px，改歪一条测试就红。

### 5. 一批"功能写好了但没接线"的死入口

| 位置 | 原来 | 现在 |
|---|---|---|
| 项目页 | 新建项目弹窗与函数**早就写好了，但没有按钮打开它**（点"新建"出来的是新建任务） | 顶部常驻「＋ 新建项目」 |
| 任务卡右键 | 「验收裁决」绑了 `status === '待验收'`，必须先拖到那一列 | 任何卡都能裁决，标题里提示会连状态一起改 |
| 看板分区 | 完全没有 | 三种摆法的分区空白处右键 →「＋ 在此列新建任务」，状态预选成那一列（不抢卡片的右键菜单） |
| 设置 · 日志 | 只增不减，没有清理 | 「清理 7 天前 / 清空全部」；文案从"把最后几十行发我"改成"你不用读，也不用发给任何人" |

### 6. 挂机提醒能关掉了

不是存储坏了：那个勾选框改完**必须点「保存挂机设置」**才落盘，勾掉就关页 = 没保存，
下次打开又读回旧值。现在勾选框与分钟数**改了就存**，保存按钮留作安全网。

### 7. AI 花销：能看到具体数字了

- 调用留痕里补上供应商返回的真实 token（入 / 出 / 合计），缺就记空，**不编数**。
- 设置页新增「💰 AI 用量」：调用次数 / 成败 / 带 token 的次数 / 入出合计 / 按模型明细 / 最近一次。
- 老记录只有字符数，界面**单列成「未计 token」的次数**，不折算成 token 糊弄人。

## 已知问题（未修，下一版）

1. **设置页控件风格仍不统一**：模型配置那一块还有原生 input/select 与新组件混排。
   这次的"42/8 统一"只覆盖了决策页；设置页要逐 tab 走查。
2. **模型通道藏得深**：在「设置 → Agent」里，项目页没有直达入口。
3. **一键填只有两家**（DeepSeek / MiMo）。MiMo 目前只预填模型名、不预填端点；
   若小米的通道不是标准 OpenAI 兼容路径，需要按实际文档适配。
4. **备份加密**没做：加密本身不难，难的是"忘记密码怎么办"要先定策略。
5. **项目方针**没有"复制给 AI 完善"的按钮。
