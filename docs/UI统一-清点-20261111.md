## 四、配方（批 1 定，批 3 / 批 4 又补了两条硬约束）

> ⚠⚠ **2026-11-11 批 4 实测更正了一条想当然的假设**：原以为"保留类名 = 保住长相"，
> 因为 `app.css` 里那些 `.todo-del{border-radius…}` 会盖住组件。**错了 —— 反了。**
> 产物 CSS 里 Tailwind utility 排在 `app.css` **之后**（`app.css` ≈ 195k，utility ≈ 238k），
> 两者特异性都是 (0,1,0)，所以**后出现的 utility 赢**；只有 `:where(button.ghost)` 那套
> （0,0,0）才会输给老类名。由此三条：
> - 迁移真正会变的属性 = **Button 写了 + 老类名也写了的那些**（背景 / 圆角 / 高度 / 内距 / 字号 / 颜色）；
>   老类名里 Button 不写的（opacity / width / white-space / margin）照旧生效。
> - 所以"悄悄矮 4px / 圆角从 999 变 8"这类偏移**不会自己消失**，必须逐条对着量。
> - 判据不能靠眼睛：批 4 在 `desktop/test/renderer-web-assert.js` 里钉了几何断言
>   （工具行 28 / 行尾静音钮 24 + 透明底 / 裁决动作 28），e2e 一跑就知道有没有走形。

1. **保留类名**：`<Button class="lp-edit" variant="ghost" size="tool" …>` —— e2e 按 `.lp-edit` 选元素，
   换组件不改选择器（改了等于把断言重写一遍，那是另一件事）。
2. **变体对应**：老 `ghost` → `variant="ghost"`；老 `pri` → `variant="primary"`；老 `danger` → `variant="danger"`；
   老 `.ok`（绿色成功态）→ **不迁**（基座没有 success 变体，reason 见 ALLOW）。
3. **尺寸对应**（批 4 补的）：老 `.ghost` 的默认档是 **28**（`--btn-h`）→ `size="tool"`；
   密集列表里的 24 档 → `size="sm"`；弹窗主按钮 34 → `size="md"`。
   ⚠ `tool` 是批 4 新加的一档：基座原来只有 24/34，拿 24 去迁工具行 = 每迁一个矮 4px。
4. **不要迁的**（登记进 `ALLOW` 并写清理由，守卫会打印）：
   - 静音钮 / 图标钮（透明底、无框、hover 才亮，如 `.todo-assign` `.todo-edit` `.todo-del`）——
     基座只有 ghost（白底带框），整排会从"安静的一组小动作"变成白框阵。**等基座补 bare 态再一起迁**；
   - 胶囊（999px 圆角，如 `.plan-pending-item`）—— Button 的圆角档只有 8/10，套上去变方角；
   - 分段选择器 / 筛选胶囊组（`.lts` `.plan-proj-chip`）—— 一组连排、选中态靠 `.on`；
   - 整行/整格可点的**伪按钮**（如 `.qd-row`）—— 换成 Button 会变成实心块、压垮行内层级；
   - 句子中间的一键切档（如 `log-task-switch`）—— Button 是块级带内边距，会把一句话拆成两行；
   - 浮层容器（`overlay/*-modal-mask`）—— 它本来就不是按钮。
5. **每批收尾**：
   - 迁走的类名从 `ui-freeze-baseline.json` 里手工删掉（**不许**用 `--snapshot` 重刷：
     那样会把 ALLOW 里那些也写进基线，"豁免理由每次打印"就失效了）；
   - `node scripts/test/check-ui-freeze.cjs` 全绿且新增 0；
   - `node scripts/test/e2e-renderer-web.cjs` 全绿（几何断言会当场抓"矮了 4px / 变白底"）；
   - 目检：新按钮与同一行老按钮**高度/圆角/字重**对得上（U2=A 的判据就是"不一致就纠"）。
