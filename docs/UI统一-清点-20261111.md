## 一、清点口径（这决定了“什么叫统一”）

`scripts/test/check-ui-freeze.cjs` 的扫描口径就是这份清单的口径：
只看**模板里的静态 `class="..."`**，对象是**原生 `<button>`**，以及 `div/section/aside` 里类名带
`modal/overlay/dialog/mask` 的浮层；`:class` 动态表达式一律不解析；
`pri/ghost/danger/font-[inherit]` 与 Tailwind utility 不算手搓。

**基线 `scripts/test/ui-freeze-baseline.json` 只许变短**：迁走一个就少一个；新增手搓件直接红。

## 四、迁移配方（批 1 已按它做）

1. **保留类名**：`<Button class="lp-edit" variant="ghost" size="sm" …>` —— e2e 按 `.lp-edit` 选元素，
   换组件不改选择器（改了等于把断言重写一遍，那是另一件事）。
2. **变体对应**：老 `ghost` → `variant="ghost"`；老 `pri` → `variant="primary"`；老 `danger` → `variant="danger"`；
   尺寸默认 `size="sm"`（卡片内动作）或 `md`（页级动作）。
3. **不要迁的**（登记进 `ALLOW` 并写清理由，守卫会打印）：
   - 整行/整格可点的**伪按钮**（如 `.qd-row`、`.qn-deck`）—— 换成 Button 会变成实心块、压垮行内层级；
   - 句子中间的一键切档（如 `log-task-switch`）—— Button 是块级带内边距，会把一句话拆成两行；
   - 浮层容器（`overlay/*-modal-mask`）—— 它本来就不是按钮。
4. **每批收尾**：
   - `node scripts/test/check-ui-freeze.cjs --snapshot` 后**核对只减不增**（ALLOW 里的类不许被写进基线）；
   - `node scripts/test/e2e-renderer-web.cjs` 全绿；
   - 目检：新按钮与同一行老按钮**高度/圆角/字重**对得上（U2=A 的判据就是“不一致就纠”）。
