# AGENTS.md - 黄泉棋境开发规则

## 1. 项目概述

本项目是一个基于 Python + Pygame 开发的剧情驱动型 13x13 围棋游戏。玩家执白，AI 执黑。游戏通过特定的落子步数触发剧情弹窗，最终在第49手提供三选一的终局抉择。

## 2. 核心架构与状态机

- 游戏状态由 `GameState` 枚举控制：`TITLE` -> `PLAYING` -> `FINALE_CHOICE` -> (`SACRIFICE_MODE` 或直接) -> `ENDING`。
- AI 落子采用**非阻塞延迟**实现，通过 `is_ai_turn_pending`（回合锁）和 `ai_action_time` 控制。
- **关键约束**：玩家落子后必须上锁 `is_ai_turn_pending = True`，AI落子后必须解锁 `is_ai_turn_pending = False`。绝对不能让玩家在 AI 回合期间通过鼠标点击落子。

## 3. 围棋逻辑规则

- 棋盘大小固定为 13x13。
- 落子合法性检查由 `go_board.py` 的 `place_stone` 处理，包括气、提子和禁入点（自杀手）。
- **AI 兜底机制**：如果 AI 计算出的落子点是自杀手导致 `place_stone` 失败，必须有一个兜底逻辑遍历全盘寻找合法的空位落子，**绝不能直接跳过 AI 回合**。

## 4. 叙事与终局规则

- 剧情节点步数硬编码在 `data.py` 的 `STORY_ARCS` 中（1, 15, 25, 40, 49）。
- 第49手触发终局弹窗。此时 `narrative.is_narrative_mode` 为 True，**必须严格屏蔽鼠标落子**，只能通过键盘 `K_1`, `K_2`, `K_3` 进行选择。
- 选择 1 (SURRENDER) 或 2 (RESIST)：直接进入结局状态 `ENDING`，不需要下第50手。
- 选择 3 (SACRIFICE)：进入 `SACRIFICE_MODE`，玩家需通过鼠标点击特定棋子完成第50手，随后进入 `ENDING`。

## 5. 音频管理规则

- SFX 包含 `place.ogg`, `capture.ogg`, `popup.ogg`。
- `popup` 音效**仅在** `narrative.check_story_trigger` 返回 True 且 `narrative.should_play_popup_sound()` 为 True 时播放。不要在普通的提子或落子逻辑中调用此音效。

## 6. 代码修改与调试规范

- 修改 `main.py` 的事件循环时，特别注意 `if/elif` 的缩进层级，过去的 Bug 常由代码块嵌套错误导致（如将普通落子代码错误包入终局状态分支中）。
- 调试时可使用 `print(">>> 状态转换...")` 来跟踪状态机流转。
- 涉及重置游戏（按 `R` 键）时，必须同时重置 `board`, `narrative`, `last_move_pos` 以及 `is_ai_turn_pending = False`。

## 7. 依赖与环境

- Python 3.x
- pygame (推荐 2.x 版本)
- 运行命令：`python main.py`

- `claims`：可选。**只有当项目负责人手算过数字时才填**，用于让方寸当场对账。没手算就删掉。
- `paths`：写相对仓库的路径。目录写 `src/foo/`，文件写 `src/foo.js`，通配写 `src/terrain*`。
