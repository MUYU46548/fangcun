## 本版内容

### 1. DSH 终于被认出来了（原先「检测不到 DSH 装了」）

方寸的 MCP 页一直认 DSH，但**技能页的「装到别的 agent」清单里从来没有 DSH 这一条** ——
所以即便上一轮你已经把技能装进 DSH，方寸那边也看不见。本版补上：

- 目标清单新增 **DSH（DeepSeek Harness）**，落点 `~/.dsh/skills`，与 Hermes **同级可直装**。
- 每个目标行给一个**「已接入」徽章** = 两个纯文件事实：**技能副本在不在** + **它的 MCP 配置里有没有 fangcun**。
  四种取值：已接入 / 部分接入 / 未接入 / **接入状态不可知**（落点查不到的，如 WorkBuddy —— 界面不谎报"未接入"）。

### 2. 技能装到哪儿，一眼看得清

- 技能卡新增一行 **「装到：Hermes ✓最新 · DSH ⬆有更新」**，逐目标显示状态（还有「（不在场）」）。
- 同时给出**真源 md5 指纹前 8 位** —— WorkBuddy 这类只能手动导入的 agent，可以拿它对账拖进去的那份是不是这一版。
- 装卡区每个可直装目标给一个 **「⚡ 装到 X」** 真按钮；Hermes 的装入口仍在顶部（不重复摆）。

### 3. 设置页分区折叠

设置项已经很多，8 个分区标题现在可以点开/收起。**默认全展开**（与旧版完全一样），
你收起来的那些会记住（存在 `prefs.json`，换访问方式也不丢）。

### 4. 看板已完成任务自动归档（默认关闭）

- 设置页新增「看板归档」：填保留天数（**0 = 关闭，默认就是 0**），可选「启动时自动执行」（默认关）。
- 看板顶部在有超期任务时出现提示条；点「移进归档区」会**先二次确认**，确认后逐条移进
  `task-data/archive/`（**只移动、不删除**，可在「归档」标签随时还原）。
- 判据是「状态=完成 **且** 更新时间超过 N 天没动过」—— 完成后再改一笔就会刷新，不会被误收。

## 已知限制（不藏着）

- 安装包未做代码签名，Windows SmartScreen 可能提示"未知发布者"，选"仍要运行"即可。
- WorkBuddy 的技能目录本机无法确认，所以它的「接入状态」显示为**不可知**（方寸不猜、也不往猜出来的目录写）。
- 「看板归档」默认关闭；开了「启动时自动执行」才会在启动时移文件（仍只移动、不删除）。
- 渲染层真点击测试需要桌面会话，受限环境自动跳过（不算通过）。
- 自动更新尚未配置发布渠道，更新按钮不会联网检查。
