## 六、遗留风险与观察项

- **bundle 体积**：本轮引 `reka-ui` 让 renderer **152KB → 175KB（gzip）**；再上 Tailwind + shadcn
  预计再 +10–20KB（桌面应用可接受，已记账在 `20261011-004`）。
- **`App.vue` 是单文件 12000+ 行** —— 任何全局 CSS 层的改动都可能连带打到它；UI 基座改造必须"零 diff 起步"。
- **`e2e-renderer`** 需真实桌面会话，本机恒 SKIP → 它的断言在本机**从未跑过**，
  真机行为仍以手动点验为准（这是既有边界，不是本轮新增）。
- **Git 备份通道**：本机验的是本地裸仓库；**真实 GitHub + 真实令牌 + 网络代理那一层没验**。
- **环境里有注入代理变量**（`http_proxy/https_proxy=127.0.0.1:64029`），git 走 https 会读它们 → 留作嫌疑。
