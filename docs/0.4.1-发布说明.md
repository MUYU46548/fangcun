**发布日期**：2026-10-24
**平台**：Windows x64（NSIS 安装包）
**安装包**：`Fangcun-Setup.0.4.1.exe`（110.8 MB）
**SHA-256**：`cda2e248ad7ed49deb07bc810b499c7eb6c30e0b1468bfde21a02ca9f86ec6d4`

## 更新简介

这一版**没有新页面**。你能看到的只有两件事：搜索框清空后板子不再锁死；agent 取活不再抢同一张卡。
其余 20 来个提交全是内部整理（App.vue 拆组件）和测试补强 —— **界面像素没变**。

## 1. 修了一个会被当成「板子坏了」的 bug

清空搜索框之后，自然查询没有退出 —— 板子一直只显示刚才那几张卡，重启才恢复。
现在清空即退出，回到全量。（这条是补断言时抓到的，不是我随手发现的。）

## 2. agent 取活加了「认领 + 租约」

`tegula next --claim hermes` 认领一张卡，写「认领人 / 认领时间」；租约 **2 小时**，过期别人能接手
（agent 崩了不会把卡锁死，锁死比重复干更糟）。`done --by` 与认领人不符会拦下 —— A 领的活不能 B 交回。
不带 `--claim` / `--by` 的老用法零变化。

> ⚠ 这条在**命令行侧**（仓库里的 `tegula/`），安装包里没有 Python CLI，装完看不到它。

## 3. App.vue 拆分（第 3–11 步）

日历、服务/端口、技能安装、路线图、回收站、待办、日志依次搬成 `views/*.vue` + composable，
App.vue 从 15877 行拆到一万出头。剩余未拆：24 个浮层（约 2000 行）、启动台、项目监控台、看板/问答/想法视图、
样式外置 —— 纯整理，像素不变。

## 4. 测试

- 新增 `scripts/test/_sources.cjs`：源码扫描型断言改扫**渲染层全量**（`rendererSource()`）或界面层
  （`viewSource()`）。拆分把代码搬走之后，写死 `App.vue` 的断言一次红了 18 条；比红更糟的是**负向判据
  变真空**（`!/X/.test(App.vue)` 在 X 搬走后照样绿 —— 绿着，但什么也没在守），这类一并改扫全量。
- 补了 6 个「恒空桩」：备份日志 / 远端备份 / 清理超期 / 日志抽屉 / 待办筛选排序统计 / 建议动作与可并行机会
  —— 之前这些界面被测到的是空数组，等于没测。
- 「⚠ N 个文件无法解析」这条防线的断言，此前一条都没有，现在有。

## 升级提示

引擎仍是 Electron 44，与 0.4.0 相同。以下几处自动化覆盖不到，装完请手工点一遍：

1. 托盘常驻 / 关窗不退
2. 通知
3. 剪贴板复制
4. 启动台拉起应用
5. MCP 桥（设置 → 接入其他 Agent 里自检）

另外建议走一轮：想法页（做 / 搁置 / 不做 + 撤销）、备份与恢复。

## 已知缺口（不阻塞使用）

- **`.vue` 没有类型门禁**：`npm run build` 只 tsc 了 main/cli，没装 `vue-tsc`。改 `.vue` 后「构建通过」
  不等于类型没问题，只能靠 `check-template-bindings` + 两层 e2e 兜。
- 拆分还剩上面列的那几块。
- `desktop/release/` 里 0.3.4–0.3.10 老包共约 788 MB，随时可清（未动）。
