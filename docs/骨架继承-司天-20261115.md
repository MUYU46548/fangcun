**〇、一句话路线**：一个账本引擎，三种读法，两种壳。

**三、烂账盘点**：7 类，每类写清「现状 / 处置」。总原则：**烂账不留情面，但只随所属模块处理**。

## 五、下一步从哪长（我的判断，一页）

### 缺口 ①：把 60+ 条铁律从 skill 搬回仓库

**为什么是第一**：`AGENTS.md` 自己写着「本文件不复制规则，防双源漂移」——**防漂移的代价是换机器就丢**。而且方寸就没读到它。

**怎么做**：不复制全文。只在仓库里建 `docs/rules/` 一个索引入口，每条一行：「编号 + 一句话 + 详细在哪」。让任何 agent 进仓库就能找到全部规则，而不是先知道要去 Hermes 里找。

### 缺口 ②：给 AI 一个"进去玩一局"的接口

**为什么是第二**：这是视频第 ⑥ 块砖，也是司天唯一没有的能力。现在 AI 改司天只能读代码 + 跑 CDP，**不能"打开软件、点两下、看对不对"**。

**这块的价值**：它直接解决你反复骂的那件事——「AI 自己不截图」「低级问题不值得我花时间看」。有了这个接口，AI 能自己进去点一遍再交。

### 缺口 ③：让总纲真的被继承

**为什么是第三**：`v1.2 总纲` 写得很好，但它是 10-20 的，之后又出了 11-09 三个月方案、11-13 INTERIOR_COPYPLAN。**每份新文档都在覆盖它，而它自己说"不再新开散件"。**

**这件事不用写代码**：在 `v1.2 总纲` 开头加一行状态——哪些章节还有效、哪些已被哪份文档取代。让"现行"这个词有唯一答案。
