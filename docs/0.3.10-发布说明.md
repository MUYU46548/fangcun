## 本版内容

### 1. 新页签「问答」：问一句就看实况（默认不花钱）

十类日常问题全部由方寸直接算（项目台账 + 任务卡 + 执行日志 + AI 花销），**零模型调用**：

| 问什么 | 答什么 |
|---|---|
| 都在哪一步 | 一行一个项目：现在做到哪、下一步是什么 |
| 下一步干什么 | 待办里优先级最高的那张卡 |
| 在等谁 | 卡在验收人还是执行人 |
| 欠着什么 | 你手写的欠账清单 |
| 卡在哪 | 哪张卡被谁挡着 |
| 哪些逾期了 | 逾期几天 + 三天内到期 |
| 哪些项目停着 | 30 天没动静的 |
| 还有多少没做完 | 未完成卡数，按状态分开 |
| 本月烧了多少钱 | 按自然月算的调用与 token |

- 每条答案都写明**来源**（"项目登记表里你手写的「说明」"这类人话，不是 `registry.yaml`）；
- 算不出来就明说「这句话结构化答不了」，旁边给「让 AI 答（会计费）」——
  **你不点，一次模型都不会调**；
- 答案底部常驻「AI 花销 · 按自然月」：只算供应商真报了用量的调用，没报的只计数、不折算。

### 2. 项目三字段可就地改，改错一步退得回

项目详情页的「状态 / 路线图 / 说明」从只能手改 `registry.yaml` 变成点一下就能改：

- 两列对齐、保存只提交**真改过**的字段；
- 保存后顶部出现撤销条（60 秒内 Ctrl+Z 同效），撤销用的是改之前的原值，不是让程序再猜一次；
- 写盘走文本块级替换 + 写前自校验：注释、字段顺序、别的项目、`released` 段一个字节都不动。

### 3. 在途一屏补齐第四栏「欠着什么」

「到哪了 / 下一步 / 在等谁 / 欠着什么」四栏齐了。第四栏读的是你手写的「说明」——
没写就显示「未写」，绝不留一句"暂无欠账"糊过去。

### 4. 一句话纠偏（决策卡自动留痕）

从「问答」的答案直接往下改，不用填表：

```
改 路线图 为 跑通第一单
把 方寸 的 状态 改成 已挂起
改 欠着 为 欠着：①模板确认 ②模型通道接管
```

只认这三种句式 —— **认不出就明说认不出、不写盘**（猜错一个方向比拒绝执行糟得多）。
改完自动记一张决策卡（出处「方寸随纠」、含"从什么改成什么"），撤销时**连决策卡一起标「已撤销」**。

### 5. 出下一批任务卡（会计费，一次调用一批）

从台账 + 决策卡派生下一批可执行任务卡：优先消化「欠着」里的事项，
每张卡写清"改哪块"和"怎么算做完"。产出一律落**「待审批」**，你点头才转正。
没指定项目 / 项目不存在时直接报错，**不会为了报个错也发一次请求**。

### 6. 13 个项目的说明换新

「状态 / 路线图 / 欠着」三字段按 10-21 的实勘稿落库（方寸 0.3.9 / 绒花墨坊 0.6.21 /
司天 M1 未起 / 明鉴降级为老作品修复 …）。写了「欠着」的项目，第四栏直接能看到。

### 7. 帮助手册拆成独立组件

内部重构（App.vue 15877 → 15754），**界面像素不变**；顺手把新增的「问答」页签补进手册
—— 手册漏页签等于手册说假话。
