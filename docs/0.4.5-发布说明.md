**发布日期**：2026-10-27
**平台**：Windows x64（NSIS 安装包）
**安装包**：`Fangcun-Setup.0.4.5.exe`（110.8 MB）
**SHA-256**：`650352622f2a28e46c23e71e8ead4b96776c22ab75b29f7a10e645dc1785d47a`

## 更新简介

**没有新功能。** 这一版只做一件事：把"界面上说的"和"实际发生的"对齐。

三个你可能会踩到的坑都修了：审批记录的时间差了 8 小时（看着像幽灵）、状态报告把"完成"报成"待验收"、
设置页那块表单压根没排过版。另加了两条守卫，防止同类问题第四次出现。

## 1. 时间差了 8 小时 —— 不是幽灵

你看某张卡上写着「[2026-10-27 04:24] 审批通过」，而那个点电脑根本没开。
查下来不是数据造假，是**时区写错了**：审批留痕取了 UTC 时间却当本地时间显示，正好差 8 小时
（真实时间是当天中午 12:24）。

同一个链条上还有两处同类问题，一并修了：

- **ai-trace 的时区**：桌面端写 UTC、命令行端写本地时间，混在同一个 `ai-trace.jsonl` 里 ——
  同一天两条记录能差 8 小时，月度报表遇到跨月还会算错月份。
- **历史记录兼容**：旧记录没有时区标记，读的时候按 UTC 解释（已实测：10-31 20:30 的记录
  现在正确归到 11 月）。

## 2. 状态报告把「完成」报成「待验收」

`tegula report` 生成的 `project-status.md` 长期在报一个不存在的数字：全库实际 0 张「待验收」，
报告写 26。原因是统计时把「完成 + 驳回」计数塞进了 `done`，而显示层又把 `done` 标成「待验收」。

现在七个状态各归各桶（草稿 / 待审批 / 待办 / 进行中 / 待验收 / 完成 / 驳回），
各桶之和等于总数。修完方寸显示`26待办, 26完成, 1驳回`，ROSA 创作那张「待审批」也终于显出来了。

## 3. 设置页的模型通道表单重排

原来那块**根本没有排版**：标签和输入框都是浏览器默认流，十几个控件挤成参差的行。
现在：标签在上、输入框满宽、模型名与超时并排、小米两套凭证的说明收进折叠。

另外两处：

- **加了一条状态条**：直接显示「已配置 / 未配置 + 上次什么时候用过、花了多少 token、用了多久」。
  以前配没配好完全看不出来。
- **三个预设按钮全保留，但加了二次确认**：以前点一下就把你填好的端点盖掉、还撤不回来。
  现在会先出一条确认，写清「A → B（API Key 不动）」，点「覆盖」才生效。配置是空的时候不问。

## 4. 表单控件有了全局基线

全站 33 条 `input` 样式规则**全是局部选择器**，唯一的全局规则只管聚焦态 —— 所以每新增一块表单
就漏一次（模型通道那四个框、模型单价那三个框都裸奔过）。现在补了基线外观
（`:where()` 包裹，特异性 0，不覆盖任何既有规则，只写外观不写布局）。
顺带把 31 处 `<code>` 也补上了等宽字体与浅底。

> 这次不是"再补一个局部样式"，是补基线 + 立守卫（`check-ui-base` 新增 7 条断言，
> 含真注入反例）。同一类问题出现第三次，就该这么办。

## 5. 打包链路

产物目录统一到 `desktop/pkg`（发版取件目录），三处路径对齐：`pack.cjs` 的 `OUT`、
`publish-release.sh` 的 `REL_DIR`、`release-precheck.py` 的资产检查。
清理脚本 `clean-release.bat` 只清历史 `release*`，**永不碰 `pkg`**。

## 升级提示

引擎仍是 **Electron 44**，与 0.4.0 起相同。以下几处自动化覆盖不到，装完请手工点一遍：

1. 托盘常驻 / 关窗不退
2. 通知
3. 剪贴板复制
4. 启动台拉起应用
5. MCP 桥（设置 → 接入其他 Agent 里自检）

设置页 → Agent → 模型通道：这次改的就是它，值得点一遍（预设按钮会先出确认条）。

## 已知缺口（不阻塞使用）

- **`.vue` 没有类型门禁**：`npm run build` 只 tsc 了 main/cli，没装 `vue-tsc`。
  改 `.vue` 后「构建通过」不等于类型没问题，靠 `check-template-bindings` + 两层 e2e 兜。
- **App.vue 仍有 14986 行未拆**（卡 `task-20261018-002`）。
- **备份的恢复演练一次都没做过**（卡 `task-20261018-004`）—— 这条比行数更值得排期。
- `desktop/pkg/win-unpacked/resources/app.asar`（0.4.4 的旧文件，36 MB）被文件索引器锁着删不掉，
  退出索引器后可手动清；不影响本版使用。
