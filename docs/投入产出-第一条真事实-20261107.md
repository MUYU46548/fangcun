## 结论（三句话）

1. **"花了 19.75 亿 token"这个数字会把人带偏 60 倍** —— 其中 **99.3% 是 `cache_read`**
   （上下文被反复重读），真正新读入的只有 **1,355 万**，模型真正写出来的只有 **387 万**。
   任何按 `total_tokens` 做的"花销排行"衡量的是**上下文有多长**，不是**干了多少活**。

2. **93% 的 token 归不到任何一张卡** —— 217 条外部调用里只有 **4 条**带 `card=`（1.8%）。
   能归到的那一张独占 **1.379 亿**：司天的「UI/UX 扫尾：157 个纯图标按钮」，状态仍是 **待办**。
   **需求归因不是"以后要做的功能"，它是现在唯一能算账的入口，而它目前的覆盖率是 1.8%。**

3. **方寸自己的 AI 调用只占整本账的 0.0024%**（10 次 / 7.6 万字符），
   而且 **5 次失败**，失败原因集中在同一个点：**模型没吐出 JSON**（plan-draft 3 次里挂 2 次、
   archGenerate 2 次全挂）。所以"方寸的规划效果差"当前不是 prompt 问题，是**结构化产出没有硬约束**。

## 这三条为什么"原来不知道"

- 之前的说法是"`ai-trace.jsonl` 有 4 次真调用"（10-27 的记忆），**现在实测是 10 次，5 次失败**；
- 之前的说法是"token 花销 × 产出能算出一条事实"，但没人核对过 **token 字段里 99.3% 是 cache**，
  也没人算过**归因覆盖率只有 1.8%** —— 按 total_tokens 排名，第一名会是"上下文最长的会话"，不是"最费钱的活"；
- "方寸的 AI 花销"一直被当成议题，实测它是 **0.0024%**：省它没意义，**它的价值全在"别再失败"**。

## 该改什么（按顺序，都是小改）

1. **口径**：报表主指标换成 `新输入 token`（prompt − cache_read）+ `completion`，
   `total_tokens` 只作副列。否则"白费可见"这条链从第一行数字就是错的。
2. **归因**：外部上报必须带 `card=`（不然 93% 永远算不出来）。
   给 `usageReport` 加一条拒收规则：`origin=external` 且无 `card=` → 记 `card=(未归因)`，
   让"没归因的那部分"在报表里**显式可见**，而不是被平均掉。
3. **状态维护**：一张吃 1.38 亿 token 的卡还挂着"待办" —— 卡面自己写着"三批落地"。
   「投入产出」要成立，卡的状态必须与真实进度同步（`expected_update` 已经有了，缺的是**按时问它**）。
4. **结构化输出**：plan-draft / archGenerate 这两条链要有 JSON 修复环（解析失败 → 抽取 JSON 片段重试一次），
   失败率 50% 不是运气问题。

## 边界（别拿这份当结论以外的东西用）

- 数据只覆盖 **10-17 → 11-06**，且外部只有 **DSH 一家**在上报；
- `cache_read` 由上报方（DSH）写在 `note` 里，是**自报**，不是方寸核出来的；
- 5 条外部 `ok=true` 但 `model` 是脏值 `m`（59 条里的一批，总量极小），不影响上述结论，但账本字段仍需要清洗；
- 方寸自己的 token 数是**按字符估的**（1.6 字符/token），因为本地调用只记了字符 —— 见第 1 条，这是口径问题的一部分。

## 复现命令

```bash
# ① 账本三分：外部 / 本地 / cache 占比 / 归因覆盖率
python - <<'PY'
import json,re,collections
rows=[json.loads(l) for l in open('ai-trace.jsonl',encoding='utf-8') if l.strip()]
ext=[r for r in rows if str(r.get('trigger','')).startswith('external:')]
loc=[r for r in rows if not str(r.get('trigger','')).startswith('external:')]
tot=sum(r.get('total_tokens') or 0 for r in ext)
cache=sum(int(m.group(1)) for r in ext for m in [re.search(r'cache_read=(\d+)',str(r.get('note') or ''))] if m)
withcard=[r for r in ext if 'card=' in str(r.get('note') or '')]
print(f'外部 {len(ext)} 条 total={tot:,} cache={cache:,} ({cache/tot*100:.1f}%)')
print(f'带 card= 的 {len(withcard)} 条（{len(withcard)/len(ext)*100:.1f}%）')
print(f'本地 {len(loc)} 条，失败 {sum(1 for r in loc if not r.get("ok"))}')
PY

# ② 那张吃 token 的卡现在什么状态
grep -n "^状态:" "task-data/uiux-扫尾还有-157-个纯图标按钮-8be49e5c.md"
```
