## 这一版做了什么

| 文件 | 说明 |
|---|---|
| `小样.html` | 主小样：改版后的决策视图（真实尺寸）+ 六主题切换 + 落地清单 |
| `小样-default.png` | 小样在默认主题下的静态截图 |

**不新造视觉语言** —— 把这轮已经定死选型的 **shadcn-vue** 那套组件长相（Tabs / Card / Badge /
Button / Input / Select）落到方寸令牌上。这是第 ④ 步「换个手搓控件」的开场，不是又一轮重设计。

三条口径：

1. **色值逐字抄自 `App.vue` 真实令牌**（默认 `:root` + 五套主题），`--ui-*` 走 `var()` 链 ——
   与刚落地的第 ② 步同构。切主题时组件 CSS 一行不动，颜色全跟着走（点小样上的主题按钮即可验证）。
2. **卡片形态替掉「一个小符号」**：原来三态只有 `✓ / ✗ / →` 一个字符，太弱；改成徽章（`有效` 绿 /
   `已撤销` 灰红 / `已合并` 琥珀），一眼看出还作不作数。已撤销的卡整卡降调 + 内容划线，但**不删**。
3. **筛选从「四个长得一样的 ghost 按钮」换成 Tabs 分段控件**，带计数（`全部 33 / 有效 25 / …`）。

## 落地时实际做的（与最初的预期有两处不同，都已注明理由）

- 新增 `components/ui/` 基础件（Button / Badge / Card / Input + `cn.ts`）+ 组合组件
  `components/DecisionBoard.vue`；`App.vue` 里那段 `<main class="decisions-view">` 换成组件标签，
  老的 `dec-*` 状态与函数整块搬走（留着就是"定义零引用"的死代码，守卫会判红）。
- `tailwind.config.js` 的 `content` 从「只扫 `components/ui/`」扩到 `components/**`
  （**仍不扫 App.vue** —— 那条是永久底线）；`check-ui-base.cjs` 的断言随之改成
  「每个 glob 必须落在 `components/` 内、不匹配 App.vue」＋新增「components/ 下每个源码文件都被覆盖到」。
- ⚠ **两处口径修正**（小样当时写的是更激进的版本）：
  ① **状态下拉仍用美化过的原生 `<select>`**（＝小样里呈现的那个长相），**没换 reka-ui Select**：
     它的浮层定位 + e2e 交互成本要单独立项，本轮不塞进来假装做到了；小样文末那张表里
     "Select（reka-ui）"一行按此修正。
  ② 小样里徽章画了 1px 描边；落地时描边色**由字色派生**（`color-mix`），不再多出三个描边令牌。
- 三态徽章色**没有写死在组件里**，而是提成 `App.vue` 的 `--badge-*-fg/bg` 令牌 ——
  这样 `check-themes.cjs` 会像量其它 13 对一样量它们（新增 3 对，共 16 对）。
