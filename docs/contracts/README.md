## 这件事为什么"无处下手"（先说清）

契约机制条款 5 规定：**AI 起草后不能自己宣布生效**，必须把「原话 + 翻译」并列念给你听，
你点头才算拟死。所以这件事天然卡在你身上 —— 但卡的是"点头"，不是"写"。

真正的约束还有一条：**方寸只读他人仓库，不能把契约写进那 6 个 repo**。
所以流程只能是三段：

1. **我起草**（已完成，6 份都在 `待签收/`）；
2. **我念、你点头**（每份 3 个选择题，你回 `A` / `B` / `C` 或"改：…"）；
3. **落盘**：由该项目的 agent（或你）把定稿写进 `<仓库>/立项契约.md`。

## 怎么念（一遍 10 分钟）

我按这个格式念一份：

```
① 终态形态
   原话：……
   翻译：意思是这个项目做到什么样就算完
   选项：A … / B … / C …（建议 A）
   你回：A 或 "改：……"
```

你只需回字母。回完我立刻写进 `## 三、签收记录` 表，并把该份状态改成**已签收**。

## 签收之后

- 该项目的 agent 拿到 `待签收/<id>.md`，把「已签收」的三段抄进它自己仓库的 `立项契约.md`（带 REV 记录）；
- 方寸的一屏从此能把这份项目显示成「已签收」而不是「未填」。

## 不做的事

- 不替你写终态（那是方针，只能你定）；
- 不把契约集中存进方寸（会造第二真相源，契约包条款 2 已否决）；
- 不在你点头前把草稿当契约用。
