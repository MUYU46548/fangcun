**主数据流（本模块数据流主线）**：
`registry.yaml`（项目登记）+ `task-data/*.md`（任务卡：frontmatter 状态机 + expected_update 锁）
→ `tegula/cli.py` 读写（经 `safe_io.atomic_write` 落盘，写前滚动备份）
→ 三条消费路径：① 看板轮询 `/tasks.json`；② `tegula report` 覆盖式生成 project-status.md；
③ `core._build_prompt` 组任务书派活
→ 执行方 `tegula done` 回写 → 置待验收 → 人裁决（accept 完成 / reject 驳回留痕）。
