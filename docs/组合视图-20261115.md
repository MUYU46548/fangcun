> **缓存读取不是烧掉的钱。** 长上下文会话每轮都会把整段 prompt 重读一遍，这部分按供应商口径计入「用量」，但它便宜一到两个数量级。

> 所以「50 亿」和「上个月 80 亿用量」是两个口径的数，**都可能是真的** —— 一个含缓存、一个不含，或者反过来。要对账必须先把口径对齐。

> ⚠ **未归因的大头是外部 agent 上报的**（`external:dsh`），它自带 `card` 的能归，不带卡的就归不了。所以「某项目 token 少」**不等于它花得少** —— 可能是花在没挂卡的会话上。

> ⚠ **2026-11-15 订正**：我第一版把未归因的 50 亿判成「明显是坏记录」，暮雨当场质疑「有没有可能真的用了 50 亿」。查完 **他是对的**：372 条记录中位数 476 万/轮，99.1% 是缓存读取。**「看起来不像真的」不等于「不是真的」——这是我这一轮最该记住的一条。**

## 4. 这张表证明不了什么（必须先看这段）

- **「完成」是自报状态。** 它不等于「真被用起来」（验收通过 / 发布 / 被引用）。本仓没有那个数据，所以本表不能回答「产出了几件真东西」。
- **token ≠ 成本。** 没填模型单价的调用只记 token、不折算金额；且不同模型单价差一个量级。
- **未归因 ≠ 没花。** 见 §3。
- **卡数 ≠ 工作量。** 一张卡可能三天，也可能是批量导入的占位。
