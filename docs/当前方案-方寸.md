## 二、主轴：抄，不自研

> 暮雨 2026-10-27 22:05：「**一堆现成的东西，哪怕抄一个一模一样的都很强，真的服了。
> 比如司天，一堆现成同类，随便完全抄一个都能用，都属于能验收通过。**」

这是今晚最硬的一条判断。**病不在缺方案，在不肯抄。**

| 要的东西 | 现成可抄 | 抄的是什么 |
|---|---|---|
| 当前方案 / 判断累积 | **ADR**（Architecture Decision Record） | 状态 / 上下文 / 决定 / **考虑过但被否掉的方案 + 为什么** |
| 需求 | **User Story + Acceptance Criteria** | 一句话角色 + 可判定的验收条 |
| 「什么算做完」 | **Definition of Done** | 一份清单，**不是一个人名** |
| 规划 | **Milestone / Phase plan** | 顺序 + 依赖 + 明确不做的 |
| 司天的地图 | **EU4 modding / map generator / QGIS 制图样式** | 整套渲染流程，不是手搓 Paradox 风格 |

**方寸唯一要自己做的**：跨项目聚合 + 与本仓库已有的卡/日志/契约/决策连上。**格式全部照抄，一条不发明。**
