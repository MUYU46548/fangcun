**发布日期**：2026-10-22
**平台**：Windows x64（NSIS 安装包）
**安装包**：`Fangcun-Setup.0.4.0.exe`（110.7 MB）

本版为开发测试版本，**不建议投入真实使用**。

## 更新简介

这一版换掉了跑了两年的引擎（Electron 28 → 44，Chromium 120 → 152），
并把方寸从"能记任务"推到了"能问、能纠、能出单"：
新增「问答」页（问一句就看实况，默认不花钱）；新增「想法」页（顺手记个念头，之后决定做不做）；
项目状态/路线图/欠着什么可以直接改、改错一步退得回；「在途一屏」四栏补齐；
还能让方寸自己出一批任务卡，并把项目上下文包一键复制给 agent。

· 一口跳到 44，不逐版升（评估报告 `docs/eval-engine-migration.md` 的结论）；
· **没有一行业务代码改动** —— 13 个用到的 Electron API 全是长期稳定件，
  28→44 之间被移除/改名的那批一个都没用到；也没有运行时原生模块；
· 渲染层 **312 条真点击断言在 Chromium 152 下零失守**（含几何与 12 个页签的对比度检查）。
安装包从 76 MB 涨到约 110 MB —— 引擎本身的体积，不是功能变多。

## 本版内容

### 1. 新页签「问答」：问一句就看实况（默认不花钱）

十类日常问题全部由方寸直接算（项目台账 + 任务卡 + 执行日志 + AI 花销），**零模型调用**；
算不出来就明说「这句话结构化答不了」，旁边给「让 AI 答（会计费）」—— 你不点，一次模型都不会调。
每条答案都写明人话来源；底部常驻「AI 花销 · 按自然月」（只算供应商真报了用量的调用）。

### 2. 项目三字段可就地改，改错一步退得回

详情页的「状态 / 路线图 / 说明」从只能手改 `registry.yaml` 变成点一下就能改：
两列对齐、只提交真改过的字段、保存后顶部出撤销条（Ctrl+Z 同效）。
写盘走文本块级替换 + 写前自校验，注释与别的项目一个字节都不动。

### 3. 在途一屏补齐「欠着什么」

「到哪了 / 下一步 / 在等谁 / 欠着什么」四栏齐了。第四栏读你手写的「说明」——
没写就显示「未写」，绝不留一句"暂无欠账"糊过去。



### 4. 新页签「想法」：念头有地方放了

随手记一句，之后决定 **做 / 搁置 / 不做**。

这一页**刻意做得很轻**：没有优先级、没有截止日、不归属项目。因为念头一旦带上这些，
就又变成待办了 —— 而"还没想好做不做"的东西本来就不该有期限，更不该按天飘红"逾期"。

| 动作 | 做了什么 |
|---|---|
| **做** | 真的在待办里生出一条（不是只改个状态），待办标题取念头的第一行 |
| **搁置** | 先放着，不是否决 —— 之后能「捡回来」 |
| **不做** | 想过了，不做。**这条会留着** —— "我想过"本身有价值 |

· 三个决定都能一步撤销（顶部撤销条 / Ctrl+Z）；
· 「已经有结论」默认收起 —— 这一页的主角是还没决定的那堆；
· **它不进任何现有口径**：不算任务、不进逾期、不进阻塞、不进在途一屏、不进待办列表。
  测试里有一条专门钉这个：记 8 条想法进来，任务卡数 / 待办数 / 在途 rows 一个都不许变。

### 5. 一句话纠偏（决策卡自动留痕）

```
改 路线图 为 跑通第一单
把 方寸 的 状态 改成 已挂起
```
只认三种句式，认不出就明说、不写盘（猜错方向比拒绝执行糟）。改完自动记决策卡，
撤销时连卡一起标「已撤销」。

### 6. 出下一批任务卡 + agent 上下文包

· **出单**：从台账 + 决策卡派生下一批可执行任务卡，一次调用一批，只落「待审批」；
  没指定项目/项目不存在时在**发请求之前**就报错。
· **上下文包**：项目详情页「📋 复制上下文包」—— 把契约 / 登记表三字段 / 方针 / 有效决策 /
  未完成卡 / 最近日志拼成一段可直接粘给 agent 的 Markdown。缺什么会明说（"缺不等于没有"）。

> 这两件是配套的：出单产出卡，上下文包让执行那张卡的 agent 一上来就知道边界。

### 7. 内部重构（界面像素不变）

· 帮助手册 / 阻塞源拆成独立组件（App.vue 15877 → 15733），账本在 `docs/app-vue-split-ledger.md`；
· `statusClass` 抽到 `shared/status.ts` 单一来源；
· 顺手补了一个洞：阻塞页的契约夹具一直返回空数组，"页里有没有东西"从来没被断言覆盖过 —— 现在有。

### 8. 13 个项目的说明换新

「状态 / 路线图 / 欠着」按 10-21 的实勘稿落库。写了「欠着」的项目，第四栏直接能看到。

## 升级提示

- 引擎换了，**装完请手工点一遍这几处**（自动化覆盖不到的）：
  托盘常驻 / 关窗不退 / 通知 / 剪贴板复制 / 启动台拉起应用 / MCP 桥（设置 → 接入其他 Agent 里自检）。
- 老数据无需迁移：`registry.yaml` 只是三个中文字段换了值，字段名一个没改。
- 「欠着什么」列在「⚙ 显示设置」里可关；老配置第一次打开会自动补上这一列（只补一次）。
