# 前端施工纪律（R1–R5）

> **唯一真源。** 适用范围：方寸及所有项目的 UI / 样式 / 交互类施工。
> 由来：2026-11-15 暮雨交来《方寸-前端施工纪律-候选条款-20261115》五条，本文件把它
> **落成本仓能执行的形态**（命令可跑、判据可机检），而不是照抄一份挂在墙上的制度。
>
> **AI 怎么看到它**：任务卡 `type: design` 或 `标签` 含 `设计` / `ui` / `design` 时，
> `_build_prompt` 会把下面 R1–R5 的硬约束随任务书下发（`UI_DISCIPLINE_BLOCK`）。
> 下发的是**要点**，全文在这里 —— 别在下发块里改口径，两处不一致就是第二真源。

---

## R1 · 视觉反馈回路（AI 侧自收敛）

- **触发**：任何涉及 UI / 样式 / 交互的改动。
- **动作**：每轮改动后**真截图**（桌面 + 窄屏两档），自己看，确认无明显丑 / 断 / 错位才可提交验收。
- **禁止**：无截图的"应该没问题"式提交。看不见自己的产出 = 盲写，**禁止盲写交付**。

本仓真身（别去装 Playwright —— 契约 REV-006 只认 Windows 11 + 零依赖）：

```bash
# 桌面档（1440×900）—— 只重拍受影响的几张，不必 40 张全跑
FC_SHOT_ONLY="planview,plandraft" node scripts/test/e2e-renderer-web.cjs --shots

# 窄屏档（900×700 = Electron minWidth/minHeight，再窄就不是产品的真实形态）
FC_SHOT_SIZE="900,700" FC_SHOT_ONLY="planview" node scripts/test/e2e-renderer-web.cjs --shots=docs/views-web-narrow

# 改完再回来跑断言（截图只证明"看着对"，证明不了"行为对"）
node scripts/test/e2e-renderer-web.cjs
```

- ⚠ **一张没拍 = 失败，不是通过**：`FC_SHOT_ONLY` 写错名字时脚本显式 `exit 2`（别再靠肉眼发现）。
- ⚠ **先删旧图再拍**：判据是"这张图是**这次**产出的"，目录里有同名文件不算。
- ⚠ **新增界面必须补截图用例**：没进 `CASES_ALL` 的页签 = 从没人看过的页签
  （2026-11-12 作战计划页可读性差就是这么攒下来的）。

## R2 · 用户实点验收（人侧终裁）

- **触发**：前端组件 / 页面完成 R1 自收敛后。
- **动作**：交付**可点实物**（装好的包，不是代码 diff、不是截图合集），用户实点 + 圈画批注，AI 按圈改。
- **完成标准**：验收线写"用户实点通过"。**禁止**用"测试绿"替代本条 ——
  测试绿只证明功能层，证不了"点着舒服"。

## R3 · 设计令牌单源

- 色彩 / 字体 / 间距 / 组件样式统一引用令牌，禁止散落硬编码。

本仓真身：

| 层 | 文件 | 判据 |
|---|---|---|
| 全局令牌 | `desktop/src/renderer/styles/app.css` 的 `:root` / `:root[data-theme]` | 主题块里出现 `--ui-*` 即违规（`check-ui-base`） |
| shadcn 映射 | 同上 `--ui-*` 块，**只许一份** | 值必须是 `var(--…)` 链，不许复制色值 |
| 组件 | `components/ui/{Button,Card,Input,Badge}.vue` | 新增手搓按钮/浮层类 → `check-ui-freeze` 红 |
| 对比度 | 六套主题逐套 WCAG | `check-themes` |

跨会话风格不漂移的唯一锚点就是这张表 —— 每个会话都重建心智模型，别指望"上次那个 AI 记得"。

## R4 · 组件小步施工

- 一次一个组件，验收通过再下一个。
- **禁止**整页 / 整应用一次性生成 —— 那是状态失控的根源。

## R5 · 完成定义（北极星）

- 前端件的"完整" = **用户零担心 + 预期不需再改**（对标备份按钮：改两三次到顶级，之后永远不用动）。
- "功能存在" ≠ 完成。"用户不用再想它"才是完成。

---

## 两回路分工（原理注记）

| 回路 | 负责人 | 治什么 |
|---|---|---|
| AI 截图自收敛（R1） | AI | 把 80% 明显丑 / 断在到用户之前收掉 |
| 用户实点圈画（R2） | 用户 | 只裁品味层 —— "舒服不舒服"只有人能判 |

不叠加的后果：盲写产物直接给用户圈，每轮圈 30 处，三轮循环必断。
叠加后：用户每轮圈 3–5 处，成本压到能长期跑的水平。
