| verdict | 含义 | 能不能当结论用 |
|---|---|---|
| **接住** | 有逐字引用，且被引用的记录**有进展**（进行中/待验收/完成/归档/提交） | 能：这是铁证 |
| **只有记录** | 有逐字引用，但记录停在待办 —— 「提了没做」的形状 | 能 |
| **疑似** | 只有弱重合（<8 字 / 非中文为主 / 路径碎片） | **不能**，要人看一眼 |
| **粘贴原文** | 这条消息**本身**就是旧记录的拷贝（重合 ≥50% 且 ≥100 字） | 不能 —— 这不是需求 |
| **无逐字引用** | 一个 ≥6 字的原文片段都找不到 | **只是下界**：卡可能用别的话写了同一件事 |
| **无法判定** | 消息太短（「继续」「0+1」） | 不能 |
