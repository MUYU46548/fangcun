## ⚠ 这条判据验的是什么（必须先读）

它验 **「有没有记录」**，**不验「有没有做」**。

- 「有没有记录」= 某张卡 / 某个提交 / 某份日志里出现过这条需求的**特定专有词**。这是**能机械证伪**的：找不到，就是真的没有任何地方提过它。
- 「有没有做」= 人的判断，本表**不做**，也不给任何「看起来做了」的暗示。

| verdict | 含义 |
|---|---|
| **接住** | 有记录，且命中的记录**有进展**（进行中/待验收/完成，或提交/日志出现） |
| **只有记录** | 有记录，但记录停在待办 —— 提过就搁下，正是「提了没做」 |
| **无记录** | **任何地方都找不到** ← 这批才是彻底悬空，最值钱的数字 |
| **无法判定** | 消息太短/太泛（「继续」），没有专有词可比 —— 不硬判 |
